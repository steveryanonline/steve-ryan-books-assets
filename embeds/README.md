# Steve Ryan Books — Carrd Embeds

Os oito arquivos abaixo usam URLs públicas externas e não possuem Base64. Em cada seção Carrd, cole um arquivo **FRONT** como `Code` e o arquivo **HIDDEN** correspondente como `Hidden`.

| Seção | Front | Hidden |
|---|---|---|
| `#home` | [Home_FRONT.html](Home_FRONT.html) | [Home_HIDDEN.html](Home_HIDDEN.html) |
| `#books` | [Books_FRONT.html](Books_FRONT.html) | [Books_HIDDEN.html](Books_HIDDEN.html) |
| `#about` | [About_FRONT.html](About_FRONT.html) | [About_HIDDEN.html](About_HIDDEN.html) |
| `#contact` | [Contact_FRONT.html](Contact_FRONT.html) | [Contact_HIDDEN.html](Contact_HIDDEN.html) |

Before publishing, replace `COLE_AQUI_A_URL_DO_WEB_APP_DO_APPS_SCRIPT` in each Hidden embed with the `/exec` URL of the Google Apps Script Web App.
